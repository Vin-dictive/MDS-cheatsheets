\section{Causal Inference Objectives}
\smalltext{
Distinguishing between \textbf{experimentally-generated} and \textbf{observational data} to evaluate causal claims. Key goals include fitting regression models that adjust for \textbf{confounding variables} and applying the principle: \code{block what you can, randomize what you cannot} in experimental designs like A/B testing.
}

\textbf{Relevance to Data Science}
\smalltext{
This block emphasizes \textbf{"joined-up thinking"} across the data pipeline. It covers randomized studies, such as \textbf{A/B testing} for website optimization, and non-randomized studies, such as assessing drug efficacy in large healthcare databases.
}

\section{Hypothesis Testing Review}

\smalltext{
\setlength{\tabcolsep}{4pt} % Reduces padding to fit column
\renewcommand{\arraystretch}{1} % Adds vertical breathing room
\begin{tabular}{|p{2.2cm}|c|c|}
\hline
\textbf{Decision} & \textbf{$H_0$ is True} & \textbf{$H_0$ is False} \\ \hline
\textbf{Fail to Reject} & \begin{tabular}[c]{@{}c@{}}Correct (TN)\end{tabular} & \begin{tabular}[c]{@{}c@{}}Type II Error (FN / Beta)\end{tabular} \\ \hline
\textbf{Reject $H_0$} & \begin{tabular}[c]{@{}c@{}}Type I Error (FP / $\alpha$)\end{tabular} & \begin{tabular}[c]{@{}c@{}}Correct (TP / Power)\end{tabular} \\ \hline
\end{tabular}
}

\smalltext{
($H_0$) represents the status quo in our case study, whereas ($H_a$) represents our hypothesis of interest.

The \textbf{p-value} is the probability of obtaining a test statistic as extreme as observed, assuming $H_0$ is true. Reject $H_0$ if \code{p-value < alpha}.
The significance level $\alpha$ will be our tolerance to type I error: rejecting the null hypothesis when in fact is true.

\textbf{Increasing Power ($1 - \beta$):} Power is the ability to detect a real effect when it exists (reducing Type II errors). Increasing power helps you find true positives, but it doesn't stop "fake" positives from appearing due to multiple testing.

When $H_0$ is True: p-values are uniformly distributed (roughly evenly spread across the interval from 0 to 1)

When $H_0$ is False: p-values are concentrated near 0 (repeated tests detect the real difference more often)

}

\begin{lstlisting}[language=R]
hypothesis.test <- function(alpha = 0.05, p_value) {
  reject <- (p_value < alpha)
  return(reject)}
\end{lstlisting}

\subsection{P-Hacking \& Type 1 Error Inflation}
\smalltext{
\textbf{p-hacking} is conducting many tests and only reporting significant results ($p < 0.05$). This inflates Type I error. For $m$ independent tests, the probability of at least one Type I error is $1 - (1 - \alpha)^m$.
}

\section{Bonferroni Correction}
\subsection{Family-Wise Error Rate (FWER)}
\smalltext{
Sets a stricter significance level: \code{alpha / m}. It ensures the \textbf{FWER} (chance of $\ge 1$ false rejection) is $\le \alpha$.
}

\begin{lstlisting}[language=R]
sum(pval < (sig_alpha / (nvars * nvars))) # Number of rejected H_0
p.adjust(pval, method = "bonferroni") # Bonferroni Adjustment in R
\end{lstlisting}


\subsection{Trade-offs}
\smalltext{
Bonferroni is \textbf{highly conservative}. It significantly increases the risk of \textbf{Type II errors} (missing real effects).
}


\begin{lstlisting}[language=R]
fdr_p <- p.adjust(raw_p, method = "fdr")# FDR/BH Adjustment in R
\end{lstlisting}


\section{False Discovery Rate (FDR)}
\smalltext{
Controls the \textbf{expected proportion of false positives} among all rejections. The \textbf{Benjamini-Hochberg (BH)} method ranks $m$ p-values ($p_{(1)} \le \dots \le p_{(m)}$) and finds the largest $k$ such that $p_{(k)} \le \frac{k}{m}\alpha$.
}

\subsection{Selecting a Correction}
\smalltext{
\textbf{Bonferroni}:if you prefer to be very conservative and would rather miss a real effect than report a fake one.
\textbf{FDR}:if you prefer to be less conservative and want to ensure you don't miss important discoveries, even if it means a small, known percentage of your results might be false positives.
}

\section{Simpson's Paradox}
\smalltext{
  Simpson's paradox occurs when a trend appearing in aggregated data reverses when the data is separated into specific groups. This often results from a limited or poor Exploratory Data Analysis (EDA). A real-world example is COVID-19 fatality rates: Italy appeared to have a higher overall rate than China, but when disaggregated by age, Italy actually had lower rates in every single age group.
  
  \textbf{To avoid misleading conclusions}, it is extremely important to know how our data was collected. Define what variables are relevant to our study. For example, if we want to infer causality, we must determine the possible causes for our outcome of interest.
}

\section{Confounding Variables}
\smalltext{
A variable $C$ is a confounder of the relationship between exposure $X$ and outcome $Y$ if:
\begin{itemize}
\item It must be related to the outcome (prognosis or susceptibility).
\item Its distribution must be different in the groups being compared.
\end{itemize}
Confounding is essentially a mixing of effects where the third factor independently affects the risk of the outcome.
}

\begin{lstlisting}[language=R]
simpson_data <- simulate_simpson(n=200, groups=4, r=0.4)
cor(data$X, data$Y) # May be negative
data %>% group_by(Group) %>% summarise(corr = cor(X, Y)) # Positive
\end{lstlisting}

\section{Dealing with Confounding}
\smalltext{
\textbf{Observational Studies:} Use stratification or regression adjustment. Include confounders $C$ as additional regressors to "block" their effect. \\
\textbf{Experimental Studies (A/B Testing):} Randomization is the "gold standard." It guarantees that treatment $X$ is independent of all confounders, allowing for causal interpretation.(ANOVA)
}

\section{TikTok Simulation Case Study}
\smalltext{
The "true" effect of the new ad was an 8-sec inc in dwell time.
\textbf{Naive Observational}: Effect overestimated because high-dwell-city users chose the new ad.
\textbf{Randomized Study}: Comparing "New" vs "Current" yielded an accurate estimate (8.22s).
\textbf{ANCOVA}: Including confounders (city/age) in a randomized model increases precision.
}

\begin{lstlisting}[language=R]
# Observational with Adjustment
lm(y_obs ~ x_self_choice + city + age, data = sample_TikTok)
# Randomized Study (ANCOVA)
lm(y_exp ~ x_randomized + city + age, data = sample_TikTok)
\end{lstlisting}

\smalltext{
To avoid misleading conclusions, know how data was collected. Randomization allows accurate estimation without knowing every confounder, but including known covariates (ANCOVA) makes estimations more precise.
}

\section{Proportion Testing (Binary Y)}
\smalltext{
When comparing means of 2 groups, \textbf{2-sample t-test}

When dealing with proportions of i groups, \textbf{Z-test}

Used for Click-Through Rates (CTR). $H_0: p_1 = p_2$.
\begin{itemize}
    \item \textbf{prop.test()}: Uses $\chi^2$ approximation. Set \code{correct=FALSE} to disable Yates' continuity correction for large samples.
    \item \textbf{One-sided}: Use \code{alternative="greater"} if testing if a new variant outperforms a baseline.
\end{itemize}
}
\begin{lstlisting}[language=R]
prop.test(x = c(clicks1, clicks2), n = c(n1, n2), alternative = "greater", correct = FALSE)
\end{lstlisting}

\subsection{Multiple Comparisons (A/B/n)}
\smalltext{
When testing $>2$ groups, the \textbf{Family-Wise Error Rate (FWER)} inflates. We must adjust $p$-values.
\begin{itemize}
    \item \textbf{Bonferroni}: Strict. $p_{adj} = \min(1, p \times m)$. High control of Type I error, but low power (high Type II error).
    \item \textbf{Holm}: Sequential, less conservative than Bonferroni. Good balance for general business/marketing use.
\end{itemize}
}
\begin{lstlisting}[language=R]
pairwise.prop.test(x = df$clicks, n = df$impressions, p.adjust.method = "holm")
\end{lstlisting}

\section{ANOVA and Factorial Designs}
\smalltext{
\textbf{Main Effect}: The avg impact of one factor (Scent) ignoring others.\\
\textbf{Interaction Effects}: When the effect of one factor changes across levels of another. Interpretation: A significant interaction means the effect of one factor depends on the level of the other factor (e.g., the effect of dose on tooth growth depends on the delivery method)\\
\textbf{Visuals}: Crossing or non-parallel lines in interaction plots = interaction.
}
\begin{lstlisting}[language=R]
mod <- aov(Receptivity ~ Scent * PickUp, data = d) # (Continuous Y)
interaction.plot(d$Scent, d$PickUp, d$Receptivity) # InteractionPlot
\end{lstlisting}

\section{Advanced Blocking}
\subsection{RCBD Design}
\smalltext{
\textbf{Randomized Complete Block Design}: Groups units into homogeneous blocks (e.g., \code{YearInSchool}) to reduce "nuisance" variance. 
\begin{itemize}
    \item \textbf{Goal}: Increase precision of treatment effect estimates.
    \item \textbf{Rule}: Treat blocks as additive terms (\code{+}), not interactions (\code{*}), unless the block itself is of scientific interest.
\end{itemize}
}
\textbf{Randomization Limit} 
\begin{itemize}
    \item \textbf{No Perfection Guarantee}: Randomization does not guarantee that groups will be perfectly balanced on every characteristic in a single experiment
    \item \textbf{Systematic Bias:}: It succeeds by breaking the systematic link between assignment and confounders, ensuring remaining differences occur only by chance
\end{itemize}
\begin{lstlisting}[language=R]
aov(Y ~ Block + FactorA * FactorB, data = d)# Model with Blocking
\end{lstlisting}

\section{Post-Hoc Reasoning}
\smalltext{
Class of experimental models refers to all possible pairwise comparisons among the levels of the main and interactions effects after the model is estimated.\\
\textbf{Tukey HSD}: Best for balanced ANOVA main effects/interactions.keeps the family-wise error rate (FWER) at 
    or below. \\
\textbf{PostHocTest (DescTools)}: Flexible for various adjustments.
}
\begin{lstlisting}[language=R]
aov_res <- aov(formula = Duration ~ Colour * Font, data = ABn_data)
tidy(TukeyHSD(aov_res, conf.level = 0.95))
PostHocTest(mod, which = "Scent:PickUp", method = "bonferroni")

\section{Experimental Design \& Strategy}
\smalltext{
  Blocking guarantees that each strata or demographic category is represented equally in both treatment groups, preventing imbalances that occur more frequently in small samples.
  
\textbf{Non-blocking}: Sampling $n$ units and randomly assigning treatments without considering strata. \textbf{Blocking}: Randomizing treatments \textit{within} each demographic category (block). This ensures sufficient representation across categories, which is critical for small sample sizes and controlling "nuisance" variance.
}

\subsection{Modelling Frameworks}
\smalltext{
The \textbf{Raw Model} regresses response $y$ on treatment $x$ only, ignoring stratum effects. The \textbf{Adjusted Model} uses post-hoc inclusion of demographic covariates. The \textbf{Blocking Model} uses data from a design where treatments were randomized within strata. While all models are accurate as $n \to \infty$, blocking models remain significantly more precise.
}

\section{Monte Carlo Metrics}
\subsection{Performance Evaluation}
\smalltext{
Simulations track behavior via four key metrics:
\begin{itemize}
\item \textbf{BIAS}: Accuracy ($E[\hat{\theta}] - \theta$). Smaller is better.
\item \textbf{RMSE}: Captures both bias and variance; typical error magnitude.
\item \textbf{COVERAGE}: \% of 95\% CIs containing the true effect value.
\item \textbf{POWER}: Probability of detecting a real effect ($\theta \neq 0$).
\end{itemize}
}

\section{Statistical Power Analysis}
\smalltext{
Power ($1-\beta$) is the probability of rejecting $H_0$ when $H_a$ is true. There is a direct trade-off between significance level ($\alpha$) and power. Sample size $n$ depends on effect size ($\delta$), variance ($\sigma$), $\alpha$, and power. Stricter $\alpha$ (e.g., 0.01) dramatically increases the required $n$.

\textbf{Sample Size (n):} The output n from pwr.t.test() represents the required number of units per treatment group, not the total. You must multiply by 2 for the total sample size

\textbf{Impact of Variability ($\sigma$):} If the population standard deviation increases, the "noise" increases. This makes the treatment difference harder to detect and increases the required sample size per group

\textbf{Standardized Effect Size (d):} Explicitly note that d is the smallest mean difference of practical importance expressed in standard deviation units
}

\subsection{Sample Size Computation}
\smalltext{
For continuous variables, use Cohen's $d = \delta / \sigma$. Blocking can achieve acceptable power with significantly less data (e.g., 10x less in high-variance contexts).
}

\begin{lstlisting}[language=R]
# Sample Size for Two-Sample t-test
pwr.t.test(d = delta / sigma, sig.level = 0.05, power = 0.8, type = "two.sample", alternative = "greater")
\end{lstlisting}

\section{Block Homogeneity}
\textbf{The Efficiency Principle}
\smalltext{
Blocking works best when blocks are \textbf{homogeneous}. Stratify units so variation in $Y$ is maximized \textit{across} blocks and minimized \textit{within} blocks. If within-block variation exceeds between-block variation, the benefits of blocking are negated.
}
