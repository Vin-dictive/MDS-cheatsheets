# UBC MDS Cheatsheets (2025–2026)

Cheatsheets for UBC MDS courses, for anyone who couldn’t make their own.

## Announcements

**New features & news**

- **Auto-generated PNGs:** This repo uses a GitHub Actions workflow to turn each PDF cheatsheet into a 4K PNG (letter-size, first page). When you push a commit, the bot runs, converts all PDFs to PNGs, and then **makes a second commit** to add or update those PNGs. So you’ll often see two commits per update: yours, then the bot’s.
- **563 cheatsheet:** Due to time constraints, I may not be able to complete a 563 cheatsheet. I’ll likely be using someone else’s for that course. If you have a 563 cheatsheet to share, feel free to open an issue or PR.

---

These reflect **my learning needs at the time I took each quiz**, so they may not cover everything. You’re welcome to:

- **Use** them as-is  
- **Copy and adapt** them for your own use  
- **Extend** them with extra material as you need  

**Missing content?** Please open an **issue**. I’ll try to update before that date. Once a quiz is over, I generally won’t update that cheatsheet anymore.
